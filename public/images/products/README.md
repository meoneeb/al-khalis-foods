# Product photos

Add `.webp`, `.jpg`, or `.png` files in this folder. `src/data/products.json` `image` paths must match the **actual filename**.

Preferred naming: `{product-id}.webp` (same as `id` in `products.json`).

## Files with different names (mapped in JSON)

| Product `id` | Filename on disk |
|--------------|------------------|
| `turmeric-powder` | `tumeric-powder.webp` |
| `quorma-masala` | `qourma-masala.webp` |
| `nihari-masala` | `nehari-masala.webp` |
| `tandori-masala` | `tandoori-masala.webp` |
| `dahi-bhally-masala-mix` | `dahi-bhallay-masala-mix.webp` |
| `macaroni-masala` | `macroni-powder.webp` |

Products without a file here use the category placeholder SVG until a photo is added.
