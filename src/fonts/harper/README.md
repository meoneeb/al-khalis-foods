# Harper (local)

| File | Weight | Use |
|------|--------|-----|
| `harper-light.ttf` | 300 | Light UI copy |
| `harper-regular.ttf` | 400 | Body / primary text |
| `harper-bold.otf` | 700 | Semibold headings, emphasis |

Loaded via `next/font/local` in `src/app/layout.js` as `--font-display` (headings). Body text uses Manrope (`--font-sans`).
